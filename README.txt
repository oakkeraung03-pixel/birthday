FOR အသေးလေး — Birthday Journey Website (mixed art + CSS animation)

START
1. Extract the ZIP.
2. Open the For-Anae-Lay-Birthday folder in VS Code.
3. Put your 3 photos in assets/memories/ as photo1.jpg, photo2.jpg, photo3.jpg.
4. Optional music files:
   music/cute-opening.mp3
   music/emotional-piano.mp3
   Without them, all website events still work; only music will be silent.
5. Install VS Code Live Server, right-click index.html, and choose Open with Live Server.

EVENT ORDER
Opening → Gift Box → 5 Reasons I Love You → Interactive Cake
(Light candles → Make a wish → Blow candles) → Birthday Wishes → Photo Memories
→ Couple Quiz → Our Story → Deep Romantic Letter → Ending

CHARACTERS
The current version uses custom CSS-drawn bear/bunny couple-inspired characters and animations so it works offline without remote GIFs. Add your own licensed/approved transparent GIF/WebP stickers later in assets/stickers/ and reference them in index.html if desired. This is Bubu/Dudu-inspired, not official artwork.

PERSONALIZE
Edit Burmese captions in index.html and the long letter in script.js. For quiz questions, edit quizData in script.js.
